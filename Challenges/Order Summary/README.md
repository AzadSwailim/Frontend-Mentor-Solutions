# Frontend Mentor - Order Summary Component Solution

This is my solution to the **Order Summary Component** challenge on Frontend Mentor. This project helped me practice building modern card layouts using **HTML5**, **CSS3**, and **Flexbox**, while improving my understanding of typography, spacing, shadows, and button styling.

---

## 📖 Overview

### The Challenge

Users should be able to:

- View the order summary card.
- See the selected subscription plan and pricing.
- Interact with the **Proceed to Payment** and **Cancel Order** buttons.
- Use the **Change** link to modify the selected plan.

## 📚 What I Learned

During this project, I practiced:

- Using SVG images as page backgrounds.
- Building reusable card layouts with Flexbox.
- Creating button shadows using `box-shadow`.
- Importing custom Google Fonts.
- Aligning icons and text efficiently.
- Styling buttons and links to match a provided design.

Example of the plan section layout:

```css
.plan-card{
    display: flex;
    justify-content: space-between;
    align-items: center;
    background-color: hsl(225, 100%, 98%);
    border-radius: 12px;
    padding: 20px;
}
```

Example of the payment button shadow:

```css
.payment-btn{
    box-shadow: 0 10px 20px rgba(56, 41, 224, 0.2);
}
```
