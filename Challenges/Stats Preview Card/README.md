# Frontend Mentor - Stats Preview Card Component Solution

This is my solution to the **Stats Preview Card Component** challenge on Frontend Mentor. This project helped me improve my understanding of **Flexbox**, **image overlays**, **custom typography**, and creating responsive card layouts using HTML and CSS.

---

## 📖 Overview

### The Challenge

Users should be able to:

- View the stats preview card on desktop and mobile layouts.
- Read the business insights and statistics clearly.
- See the purple accent overlay applied to the header image.

## 📚 What I Learned

During this project, I practiced:

- Creating two-column layouts using Flexbox.
- Positioning elements with `position: relative` and `position: absolute`.
- Building image overlays with semi-transparent accent colors.
- Importing and using Google Fonts.
- Structuring reusable card components.
- Improving spacing and typography for readability.

Example of the image overlay:

```css
.overlay{
    position: absolute;
    inset: 0;
    background-color: hsl(277, 64%, 61%);
    opacity: 0.5;
}
```

Example of the statistics layout:

```css
.stats{
    display: flex;
    justify-content: space-evenly;
    align-items: center;
}
```
