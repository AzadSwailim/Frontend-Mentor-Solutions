# Frontend Mentor Solutions

This repository contains my solutions to various challenges from **Frontend Mentor**. These projects are built to improve my frontend development skills by practicing responsive layouts, semantic HTML, modern CSS, and JavaScript.

## About

Frontend Mentor provides real-world UI challenges that help developers improve their coding skills by recreating professional designs.

This repository serves as my personal collection of completed challenges and documents my progress as I continue learning frontend development.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Flexbox
- CSS Grid
- Responsive Web Design

## Repository Structure

Each challenge is organized in its own folder.

Example:

```text
Frontend-Mentor-Solutions/
│
├── qr-code-component/
├── product-preview-card/
├── blog-preview-card/
├── social-links-profile/
└── README.md
```

Each project contains its own source files and assets.

1. Clone the repository

2. Open any project folder.

3. Launch the `index.html` file in your browser.
