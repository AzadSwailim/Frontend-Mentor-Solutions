# Frontend Mentor - Blog Preview Card Solution

This is my solution to the **Blog Preview Card** challenge on Frontend Mentor. The challenge helped me practice building responsive card layouts using HTML and CSS while improving my understanding of Flexbox, spacing, typography, and component styling.

## 📖 Overview

- How to create content-sized elements using `width: fit-content`.
- How to apply spacing using padding and margins.
- How to create simple card shadows using `box-shadow`.
