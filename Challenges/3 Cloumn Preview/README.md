# Frontend Mentor - 3 Column Preview Card Component Solution

This is my solution to the **3 Column Preview Card Component** challenge on Frontend Mentor. The project helped me practice creating responsive multi-column layouts using **HTML** and **CSS**, while improving my understanding of **Flexbox**, **custom typography**, **spacing**, and **button styling**.

---

## 📖 Overview

### The Challenge

Users should be able to:

- View a clean three-column card layout.
- See different background colors for each card section.
- Read clearly structured content with proper typography.
- Interact with the "Learn More" buttons.
- View a responsive design that adapts to different screen sizes.

---

## 🛠️ Built With

- HTML5
- CSS3
- Flexbox
- Google Fonts
  - Big Shoulders Display
  - Lexend Deca

---

## 📚 What I Learned

While building this project, I practiced:

- Creating multi-column layouts using **Flexbox**.
- Applying different background colors to separate content sections.
- Using multiple Google Fonts within the same project.
- Improving typography with font families, sizes, and line spacing.
- Designing rounded buttons with custom colors.
- Managing spacing using padding and margins.
- Using `overflow: hidden` with rounded containers.

---

## 🚀 Features

- Three-column card layout
- Custom Google Fonts
- Rounded card container
- Individual colored sections
- Styled "Learn More" buttons
- Clean typography and spacing
- Beginner-friendly HTML & CSS structure
