# Frontend Mentor - Product Preview Card Component Solution

This is my solution to the **Product Preview Card Component** challenge on Frontend Mentor. The project helped me practice building responsive card layouts using **HTML** and **CSS**, while improving my understanding of Flexbox, typography, custom fonts, and button styling.

---

## 📖 Overview

### The Challenge

Users should be able to:

- View the product preview card on different screen sizes.
- See a clean layout matching the provided design.
- Interact with the "Add to Cart" button.

## 📚 What I Learned

While building this project, I practiced:

- Importing and using Google Fonts.
- Combining Flexbox with spacing and alignment.
- Styling buttons with icons.
- Using `letter-spacing` for category labels.
- Working with semantic HTML structure.
- Creating clean card layouts using modern CSS.

Example of the button layout:

```css
.btn{
    display: flex;
    align-items: center;
    justify-content: center;
    gap: 10px;
}
```
