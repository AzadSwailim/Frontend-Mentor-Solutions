# Frontend Mentor - NFT Preview Card Component Solution

This is my solution to the **NFT Preview Card Component** challenge on Frontend Mentor. The project helped me improve my understanding of **Flexbox**, **card layouts**, **custom typography**, and creating modern UI components using HTML and CSS.

---

## 📖 Overview

### The Challenge

Users should be able to:

- View the NFT preview card with the provided design.
- See the NFT image, title, description, price, and remaining time.
- View the creator information.
- Experience hover effects on interactive elements.

## 📚 What I Learned

While building this project, I practiced:

- Building card layouts with Flexbox.
- Importing and using Google Fonts.
- Aligning icons and text using Flexbox.
- Styling horizontal dividers.
- Creating consistent spacing using margins and gaps.
- Structuring reusable HTML components.

Example of the Flexbox layout used for the information section:

```css
.info{
    display: flex;
    justify-content: space-between;
    align-items: center;
}

.eth{
    display: flex;
    align-items: center;
    gap: 10px;
}
```
