# Frontend Mentor - Results Summary Component Solution

This is my solution to the **Results Summary Component** challenge on Frontend Mentor. The project helped me improve my understanding of **Flexbox**, **CSS gradients**, **responsive layouts**, **hover animations**, and creating reusable UI components with HTML and CSS.

---

## 📖 Overview

### The Challenge

Users should be able to:

- View the results summary component with the provided design.
- See clearly separated score categories with their respective scores.
- Experience hover effects on the summary cards and button.
- View a clean and responsive card layout.

## 📚 What I Learned

While building this project, I practiced:

- Creating layouts using Flexbox.
- Using `linear-gradient()` and `radial-gradient()`.
- Styling SVG icons.
- Building reusable card components.
- Applying transitions and hover effects.
- Structuring HTML for better readability.

Example of a hover animation:

```css
.btn {
    transition: all 0.3s ease;
}

.btn:hover {
    background-color: #22213d;
    transform: translateY(-3px);
}
```
